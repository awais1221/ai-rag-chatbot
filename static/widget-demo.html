This page stands in for a client's site. The chat bubble in the corner is the widget.

👉 Click the chat bubble in the bottom-right corner and ask a question about the documents in the knowledge base.

Add it to any website with one line

Paste this before the closing </body> tag. It works with WordPress, Shopify, Wix, Webflow, React/Next.js or plain HTML:



    
Options

    
    
      
  • data-title: the name shown in the chat header
    • 
      
  • data-color: your brand color (hex)
    • 
      
  • data-greeting: the first message visitors see
    • 
      
  • data-position: right (default) or left
    • 
    

    
The widget uses a Shadow DOM, so your site's CSS can't break it, and it keeps the conversation
      while visitors move between pages.
